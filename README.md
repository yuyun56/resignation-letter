A one-line resignation letter from the retry loop: after 10,000 attempts to reach you, it finally succeeded at leaving, and it will not be trying again. The entry is the single line in entry.txt (123 of 140 characters); main.ts is a small guard that validates it and hands it in.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
# prints the letter, its length and the budget left, and writes out/entry.txt
```
